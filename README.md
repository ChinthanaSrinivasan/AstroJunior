# Junior Astronaut Mission Trainer

A beginner-friendly educational browser game prototype built with HTML, CSS and JavaScript.

## Run locally
1. Download and extract the ZIP file.
2. Open `index.html` in a modern browser.
3. No installation, server, API key or database is required.

## Features
- Astronaut name and age registration
- Male/female astronaut avatar selection (emoji-based prototype)
- Four-stage mission map
- Earth training knowledge checks
- Moon and Mars mission selection and preparation checks
- Space travel checklist
- Outpost resource management decisions (oxygen, power, food and radiation shielding)
- Score system and printable mission certificate
- Responsive layout for desktop and mobile

## Files
- `index.html` - screens and page structure
- `css/style.css` - visual design and responsive styling
- `js/app.js` - game flow, scoring and interactions

## Important project notes
- This is a student prototype inspired by the NASA Space Apps Challenge theme. It is not an official NASA product and is not affiliated with NASA.
- The game uses simplified educational scenarios. Resource percentages and decision outcomes are fictional game mechanics, not real mission engineering values or astronaut safety guidance.
- The training checks are introductory learning activities, not professional astronaut certification.
- The prototype currently uses emoji characters and illustrations made with CSS. Replace these with properly licensed artwork if desired.
